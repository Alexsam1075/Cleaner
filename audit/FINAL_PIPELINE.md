# Финальный конвейер Astramis (audit/)

Запуск сабмита на тест (сервер, `~/Cleaner/audit`):
```bash
export ASTRAMIS_DATA=/home/cleaner/Cleaner/datasets/raw
~/venv/bin/python predict_test.py --prompts rich --take hybrid --agg 0.90 --out submission_final.csv
```
Все модели обучаются на 40 train-объектах (real_train + synth_train); `real/test` используется только для инференса.

## Этап 1 — покадровая оценка
| Блок | Реализация | Файл |
|---|---|---|
| Рамки, маски | YOLO11n-seg, 640 px, 18 эпох, real+synth, обучен на всех 40 объектах | `final_detector.py` → `final/det_all/weights/last.pt` |
| Форма (bulk/solid) | линейная голова на CLIP-L (объект с контекстом) ⊕ zero-shot; score рамки = conf × p(форма); NMS 0.6; отсев рамок у края | `agents/form/form_model.py`, `predict_test.py` |
| Материал | линейная голова CLIP-L c14 ⊕ zero-shot CLIP-L+SigLIP; описания `rich` («a brown glass bottle», «an aluminium can», «a dark painted metal tray», …); вес zero-shot — внутренний 5-fold CV | `full_pipeline.material_model`, `PROMPT_SETS` |
| Объём | `volume/` (объём по частям + калибратор ridge, обучен по GT-маскам 40 объектов), геометрия считается по форме классификатора | `volume/estimator.py`, `full_pipeline.volume_estimator_for` |
| Масса | объём × медианная плотность класса (в метрике не участвует) | — |
| take | **гибрид**: metal/glass/mineral — калиброванный объём ≤ T (T ≈ 427 мл, подобран на 40 объектах); paper/plastic/wood — масса = объём × плотность класса (по train) ≤ 500 г. На фолдах S 0.842 → 0.907, Score +1.0 | `predict_test.py --take hybrid` |

## Этап 2 — обобщение по «похожим деталям»
| Шаг | Правило | Проверка на фолдах |
|---|---|---|
| Поиск той же детали | соседние кадры (разрыв ≤ 3), косинус CLIP-L+SigLIP ≥ 0.90 | смешанных групп 0 |
| Объём / take | медиана log-объёма по группе → take | +0.5 Score |
| Материал, форма | **не усредняются**: голосование по серии роняло M (0.916 → 0.79–0.88), ошибки материала общие для всей серии | `two_stage.py`, `object_memory.py` |
| Вторая форма | **выключена по требованию**: одна рамка на объект (`--two-class-all` даёт D 0.884 → 0.975, +3.6, но это дубли) | — |

## Что проверено и не вошло (все цифры в `*.log`)
большой детектор yolo11s/960 (D не растёт), TTA, IRLS-объём (+0.002), take-модель агента (хуже порога), zero-shot «заполнение», формулы фигур, якорь по плитке, синтетика по глубине (вредит), пороги take по квантилю теста и по группам материала, усреднение материала по сериям, физические подсказки «блики/серебро» (на баллончике бликов 1%, не отличимо от пластика).
