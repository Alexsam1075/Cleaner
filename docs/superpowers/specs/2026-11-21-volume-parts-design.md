# Объём по частям предмета с учётом класса

Дата: 2026-11-21. Статус: черновик, ждёт согласования.

## Зачем

V (объём) весит 25% итога, и на нём теряется больше всего (~12 пунктов из 28 на лучшем fold 2).
Тестовые предметы новые, поэтому объём нельзя запомнить по предмету: его надо измерять по
размеру, высоте и глубине кадра, учитывая отдельные части предмета и его класс.

## Что есть сейчас

`geometry/features.py`: облако точек → высота над полом → сумма столбиков по сетке 4 мм.
На идеальных масках из разметки (real train, 214 объектов) V = 0.565. Ошибки систематические:

- мелкие предметы (дерево 12–40 мл, минерал 80 мл) завышены в 2–7 раз: шум высоты у пола и по краям маски;
- крупные и стекло (b06 1400 мл, s08 2400 мл, s04) занижены в 2–3 раза: не видна задняя сторона, дыры в глубине;
- разброс между кадрами одного предмета мал (std лог-отношения ~0.1), то есть ошибку можно исправить расчётом.

## Цели / не цели / анти-цели

- Цель: V ≥ 0.70 на независимых folds по `object_id` (на GT-масках и на предсказанных масках).
- Не цель: менять детектор и классификатор материала.
- Анти-цель: прирост, который получается запоминанием 40 предметов; подбор чего-либо по внешнему fold.

## Ограничения

- Своё решение; предобученные сети не используем. Открытый код с GitHub можно (например, RANSAC-подгонка фигур).
- Считаем и обучаем на сервере aion-lab (`~/Cleaner`, Python `~/venv`), GPU делим с чужими процессами.
- Плотность по классу известна (`densities.csv`), масса предмета на тесте неизвестна.

## Подходы

1. **Геометрия по частям + класс (выбран).** Своя геометрия, класс подсказывает форму и поправку.
2. Своя нейросеть по карте высот с нуля: на 40 предметах почти наверняка запомнит предметы. Отклонён.
3. Регрессор по признакам без частей: уже пробовали, V ≈ 0.52. Отклонён как основной.

## Как устроено (подход 1)

1. **Чистка.** Маска сжимается на 2–3 px; точки ниже 3–5 мм над полом отбрасываются как шум;
   плоскость пола уточняется по кольцу вокруг маски.
2. **Части.** Облако над полом режется вдоль главной оси отпечатка на срезы; соседние похожие срезы
   склеиваются в части (тело и горлышко бутылки, отдельные комки кучи).
3. **Фигура на часть.** Для каждой части — цилиндр, коробка или эллипсоид по видимой половине;
   задняя сторона достраивается по симметрии; дыры в глубине закрываются по контуру маски.
4. **Класс (форма × материал из классификатора).** Задаёт, какие фигуры пробовать (куча → купол/эллипсоид,
   solid → цилиндр/коробка), и даёт небольшую поправку по классу, обученную только на train-объектах.
   Плотность из `densities.csv` даёт массу = объём × плотность для решения take.
5. **Итог.** Несколько оценок (сумма фигур, столбики после чистки, выпуклая оболочка) смешиваются
   маленьким регрессором в лог-шкале; подбор только grouped OOF по `object_id`.

Проверка: сначала на GT-масках (чистая оценка геометрии), затем на предсказанных масках текущего детектора;
таблица V по folds, по классам и по корзинам объёма.

## Решения, оставленные исполнителю

Точные пороги чистки, число срезов, набор фигур, тип регрессора — подбираются на train-folds.
